Foundations Path

This website originates from lesson Landing Page located in Foundations Path.

Foundations Path teaches basics of following topics:

  • Git

    Git is versioning system. User of git records the history of a project by versioning it, commiting changes to repository (local or remote). It is not exclusive to programming and can be used to different projects. Git also allows people to collaborate on a project.

  • HTML

    HTML (Hypertext Markup Language) is markup language used to put content on a website. It has Elements that consist of opening and closing tags (some Elements have a single tag). Most of its Elements have semantic meaning used by screen readers.

  • CSS

    CSS (Cascading Style Sheet) is used to style HTML content. Without CSS, websites would not look attractively. Every browser has its own set of default styles applied to HTML Elements.

  • JS

    JS (JavaScript) is programming language that gives websites functionality. It would not be possible to interactively change website content. For example, website calculator would not calculate.
