The Odin Project website is awesome

The Odin Project is completely free and open to everyone. People around the world can learn web development at their own pace, without paying a cent. Its curriculum is open source, so anyone can see how it is made and help improve it. Knowledge is shared rather than sold, which makes it fair for everyone. It is an investment in people, and many of them give back by helping others and contributing to the web.

Foundations Path

This website originates from lesson Landing Page.

Foundations Path teaches foundations about following topics:

HTML (Hypertext Markup Language) is markup language used to put content on a website. It has Elements that consist of opening and closing tags (some Elements have a single tag). Most of its Elements have semantic meaning used by screen readers.

CSS (Cascading Style Sheet) is used to style HTML content. Without CSS, websites would not look attractively. Every browser has its own set of default styles applied to HTML Elements.

JS is programming language that gives websites functionality. It would not be possible to interactively change website content. For example, website calculator would not calculate.

Git is versioning system. User of git records the history of a project by versioning it, commiting changes to repository (local or remote). It is not exclusive to programming and can be used to different projects. Git also allows people to collaborate on a project.
